# RockWorthi: AI Productivity Hub

**RockWorthi** is an elegant, mobile-first AI productivity workspace built for modern professionals. Designed with a calm, uncluttered UI, it streamlines writing, recall, and planning in seconds. 

This project was developed as part of the CAPACITI AI Skill Accelerator Programme & Google AI Essentials Certification.

## 🚀 Core Features

* **Smart Email Generator:** Turns rough ideas into send-ready emails based on the sender's name, context, and desired tone.
* **Meeting Notes Summarizer:** Converts raw, messy meeting notes into clean executive summaries with clear action items and owners.
* **AI Task Planner:** Captures tasks alongside dates/times, and generates a prioritized, structured weekly schedule based on urgency.

## 💻 Tech Stack
* **Frontend:** React, TypeScript, CSS
* **Development & Deployment:** Built and deployed using Lovable
